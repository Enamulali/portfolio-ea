# itsenam.dev

My personal portfolio. Live at [itsenam.dev](https://itsenam.dev).

![The site](public/design/after.webp)

Built with React, Vite and Tailwind, deployed to Cloudflare Workers. React renders the page to static HTML at build time (`prerender.js`), so the only script a visitor downloads is the before and after slider (`src/slider.js`).
